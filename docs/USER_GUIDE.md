# User Guide – Fitness Tracker

## 1. Account
- **Signup:** Name, username, email, password bharein, optional profile picture lagayein,
  Terms aur Privacy Policy tick karein, phir Sign Up.
- **Login:** Email ya username aur password.
- **Password bhool gaye:** Login page par "Forgot password" se email par link aata hai.

## 2. Daily tracking (sidebar → Log)
- **Workouts:** Exercise, sets, reps, weight, duration add karein. Search aur filter kar sakte hain.
- **Nutrition:** Khana, calories, protein/carbs/fats add karein.
- **Weight:** Apna weight add karein. Dashboard par progress chart dikhta hai.
- **Measurements:** Chest, waist, hips, arms, thighs. Neeche progress chart hai.
- **Performance:** Strength (kg) ya cardio (minutes/km) records.

## 3. Analytics aur Reports
- **Workout Analytics:** Kisi exercise ka progress chart (unit ke saath) aur weekly frequency.
- **Nutrition Analytics:** Calories, macros aur meal-wise charts.
- **Reports:** Data CSV ya PDF mein export karein.

## 4. Goals aur Reminders
- **Goals:** Target weight, weekly workouts, daily calories set karein.
- Goal poora hone par notification aati hai.
- **Reminders:** Workout/meal ka time set karein (app khuli hone par chalte hain).

## 5. Notifications (bell icon)
Workout complete, milestone, streak, goals, naye followers aur forum replies.
Notification par click karein to seedha wahi page khulta hai.

## 6. Community
- **Suggested:** Naye users jinhein follow kar sakte hain.
- **Find Users:** Naam ya username search karein.
- **My Followers / Following:** Apni list dekhein, Follow/Unfollow karein.

## 7. Forum
Naya post likhein, dusron ki posts par reply karein, posts mein search karein.
Apni post/reply delete kar sakte hain.

## 8. Profile aur Settings
- **Profile:** Naam, username, email, photo, password badalna, account delete.
- **Settings:** Theme (light/dark), units (kg/lbs, cm/in), notification on/off.
- **Support:** Masla ya sawal bhejein.

## 9. Privacy
Aap apna data export (CSV/PDF) kar sakte hain aur Profile se account delete karke saara data mita sakte hain.
